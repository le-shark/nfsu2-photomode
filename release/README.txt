Press End to activate, Space to take a photo. By default the screenshots go to the screenshots/ folder in the game folder.
Send feedback to @wilmanwdk on discord. Plase report any bugs you encounter or features you would like added

more keys:
wasd - move the camera around
e/q - move the camera up/down
c/z - roll the camera
shift - move the camera faster
ctrl - move the camera slower
mouse wheel - focal length (zoom), ctrl + wheel - smaller steps
[/] - change focus target
h - show/hide hud
ctrl + left/right on focal length/focus distance in Manual focus mode - smaller steps
v - drive the car in photo mode
t - toggle rival tags (for focus target assistance)
r - toggle rain drops

to upload custom watermarks: create a "watermarks" folder in the game's scripts/ folder and drop the watermarks there.

gamepad controls:
L3 + R3 - open
start - close
back - drive mode
a - take picture
b - toggle hud
y / x - zoom in / out
left stick - move camera
right stick - look around
lt / rt - move camera up/down
lb / rb - roll camera
